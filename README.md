[![JavaScript](https://img.shields.io/badge/JavaScript-ES6-F7DF1E?style=flat-square&logo=javascript&logoColor=black)](https://developer.mozilla.org/)
[![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)](https://developer.mozilla.org/)

> Fast, client-side text manipulation and lexical analysis utility designed to transform text cases, remove extra whitespaces, compute word/character frequencies, and estimate reading time.

---

## ⚡ Transformations & Tools

- **Case Conversions:** UPPERCASE, lowercase, Title Case, Sentence case.
- **Lexical Metrics:** Real-time character counts, word counts, and estimated reading duration.
- **Text Sanitization:** Automatic double/trailing space removal and clean line break handling.
- **One-Click Clipboard:** Direct clipboard copy and preview clearing.
- **Dark Mode Support:** Smooth contrast switching for comfortable reading.

---

## 🚀 Quickstart

```bash
git clone https://github.com/mesumali-dev/text-utils-app.git
cd text-utils-app

npm install
npm start
```
